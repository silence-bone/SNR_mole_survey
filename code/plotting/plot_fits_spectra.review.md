# FITS 谱线叠加绘图脚本

`plot_fits_spectra.py` 用于直接查看输入 FITS 的原始谱线。它独立于已有拟合和 window profiles 的分析流程，只复用 `profile_plot_style.py` 的字体、字号和刻度样式：正文为 serif，数学字体为 dejavuserif，坐标标签 22、刻度 18、图例 12。原有脚本与数据没有改动。

## 使用方式

在脚本开头的 `SPECTRA` 中逐条填写 `file`、`rgb` 和 `label`，然后运行：

```bash
python code/plotting/plot_fits_spectra.py
```

`rgb` 固定采用 0–255 标度，例如 `(255, 0, 0)` 是红色；设为 `None` 使用 Matplotlib 自动配色。`label=None` 使用带扩展名的完整文件名，也可填写自定义字符串。`SPECTRA` 内的相对输入路径相对于项目根目录解析，绝对路径直接使用。默认提供 3C391SW 的两条谱作为可运行示例；修改列表即可绘制自己的数据。

`VELOCITY_WINDOW` 默认为 `(-100, 200)` km/s。图幅、分辨率、线宽、标题、纵轴范围、图例位置以及是否打开图片都集中在顶部。`Y_LABEL=None` 时按 FITS 的 `BUNIT` 标记强度；当多条谱的 `BUNIT` 不同，在各自图例后分别附上单位或温度标度，纵轴写 Intensity。不做单位统一或温度标度换算。

也可以直接从命令行指定文件、窗口、颜色和图例：

```bash
python code/plotting/plot_fits_spectra.py \
  snr_data/3C391SW_12CO21.fits snr_data/3C391SW_12CO43.fits \
  --window -100 200 \
  --colors 40,90,210 220,65,45 \
  --labels 'CO 2-1' 'CO 4-3'
```

命令行文件替代 `SPECTRA`，未指定颜色时自动选色，未指定图例时使用文件名。`--colors` 与 `--labels` 各自的数量必须等于输入文件数，顺序一一对应；只传其中一个选项也可以。命令行相对输入路径和 `--output` 相对路径都以当前运行目录为基准。在其他目录运行时可提供脚本绝对路径；不带文件参数时仍能找到顶部配置的项目内输入。依赖为 NumPy、Astropy 和 Matplotlib，项目的 `snr_env` 已具备。

## 读取与绘图方法

脚本读取主 HDU，将单元素维度移除后要求数据为一维，且第 1 个 FITS 轴为谱轴。因此支持项目常见的 `(1, 1, 1, N)` 文件，不隐式平均二维图或三维数据立方体，也不读取二进制表谱。

速度换算优先沿用项目 CLASS 文件的 `VELO-LSR`、`DELTAV`、`CRPIX1`，按 m/s 换成 km/s。这一分支与现有 window profiles 的读取规则相同。没有这组卡片时，标准线性速度轴使用 `CRVAL1`、`CRPIX1`、`CDELT1` 和 `CUNIT1`；标准 FREQ 轴使用静止频率 `RESTFRQ` 或 `RESTFREQ`（Hz），按 radio 定义计算 `v=c(1−ν/ν₀)`。对 `CRVAL1=0` 且存在 `VELO-LSR` 的 CLASS 频率偏移轴使用 `v=VELO-LSR−cΔν/ν₀`。缺省速度单位为 m/s，缺省频率单位为 Hz。非线性谱轴会明确报错，不套用线性公式。脚本沿用输入头所定义的速度参考系，不另外进行 LSR、日心或重心参考系修正。

所有通道按速度升序排序，用通道中心阶梯线叠加，谱线和图例顺序保持输入顺序。NaN 保留为断点。横轴固定为指定窗口，自动纵轴范围只考虑窗口内的有限强度，并在上下各留 5% 的余量；常数谱保留最小余量。若任一输入在窗口内没有有效通道，则报错而不生成一个缺谱的图。原始强度不扣基线、不合并通道、不做波束效率校正，也不应用倍率或纵向偏移。

## 输出与连续运行

默认输出到项目根目录 `output/fits_spectra/`，格式为 PNG，名称为 `<首条输入文件名去扩展名>_spectra_年月日_时分秒_微秒.png`。时间戳使用本机时间，避免常规连续运行覆盖上一张图片。通过 `OUTPUT_FILE` 或 `--output` 指定文件时按扩展名保存，并覆盖同名文件；因此希望保留多次结果时应使用默认时间戳或每次指定不同名称。输出文件名、图例和标题中出现的 W44 分区名统一写为 W44W、W44N、W44C、W44S，实际输入路径保持原样。

脚本使用 Agg 完成保存并释放内部 Figure，随后通过系统查看器打开文件。macOS 使用异步启动的 `open`，Linux 使用 `xdg-open`，Windows 使用 `os.startfile`，不调用阻塞的 `plt.show()`。图片交给独立查看器后脚本即可结束，旧图片无需关闭便能再次运行。这里展示的是保存后的图片；查看器需要由运行脚本的本机桌面环境提供。使用 `--no-show` 可只保存图片。
